# White Fang Medical Research

**White Fang (WFANG)** — *Supercomputer fighting disease.*

A Scrypt proof-of-work cryptocurrency with a second purpose: every coin mined
helps medical research. The chain is secured by Scrypt miners, and anyone with
a CPU or GPU can earn WFANG by contributing compute to
[Folding@home](https://foldingathome.org) protein-folding research —
no ASIC required.

*Every coin mined helped research.*

## Status

Early stage — branding locked, whitepaper v1 drafted. No code yet, no launch
date. Fair launch, no premine.
